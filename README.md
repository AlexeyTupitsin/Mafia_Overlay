# Графика трансляции спортивной мафии

Веб-приложение для трансляций: **панель ведущего** + **оверлей для OBS** (Browser Source).
Сервер хранит состояние игры и мгновенно синхронизирует панель и оверлей по WebSocket.

Работает одинаково на **Windows** и **macOS** (и на Linux) — всё, что нужно, это Node.js.

## Как скачать

Без установки Git — архивом:

1. Откройте страницу проекта: <https://github.com/AlexeyTupitsin/Mafia_Overlay>
2. Зелёная кнопка **`< > Code`** → **Download ZIP**
   (прямая ссылка: <https://github.com/AlexeyTupitsin/Mafia_Overlay/archive/refs/heads/main.zip>).
3. Распакуйте архив в любую папку.

> В архиве **нет** папки `node_modules/` и файла `config.json` — их добавлять не нужно:
> зависимости ставятся командой `npm install` (см. ниже), а `config.json` требуется только
> для интеграции с трекером рейтинга и для обычной работы оверлея не нужен.

## Что установить

1. **Node.js 20 LTS или новее** — единственная обязательная зависимость.
   Скачайте с официального сайта <https://nodejs.org/> и установите со всеми настройками
   по умолчанию.
   - *Windows:* запустите скачанный `.msi` и жмите «Далее».
   - *macOS:* запустите скачанный `.pkg`, либо через Homebrew: `brew install node`.

   Проверить установку (в терминале/командной строке):
   ```
   node --version
   ```
   Должна показаться версия `v20…` или выше.

2. **Google Chrome** — нужен **только** для дев-утилиты скриншотов (`tests/test-shot.mjs`).
   Для обычной работы трансляции не требуется.

## Установка проекта

В терминале перейдите в папку проекта и один раз выполните:
```
npm install
```
Команда скачает зависимости (Express, ws, multer, sharp) в `node_modules/`.

> **Как открыть терминал в папке проекта**
> - *Windows:* откройте папку в Проводнике, в адресной строке наберите `cmd` и нажмите Enter.
> - *macOS:* в Finder откройте папку, правый клик → «Новый терминал в папке».

## Запуск

Кросс-платформенный способ (Windows, macOS, Linux):
```
npm start
```

*Windows:* для удобства можно просто дважды кликнуть по `start.bat` — он сам запустит сервер.

После старта в консоли печатаются адреса. Откройте:
- **Панель ведущего:** <http://localhost:3000/control> — в обычном браузере;
- **Оверлей:** <http://localhost:3000/overlay> — добавляется в OBS (см. ниже).

Порт настраивается в `config.json` (поле `port`) или переменной окружения `PORT`.

### Панель с планшета

Планшет должен быть в той же сети, что и компьютер трансляции. На планшете откройте
`http://<IP-адрес-компьютера>:3000/control` — адрес печатается в консоли при старте сервера.

## Добавление оверлея в OBS

1. Источники → **+** → **Браузер** (Browser Source).
2. Настройки источника:
   - URL: `http://localhost:3000/overlay`
   - Ширина: **1920**, высота: **1080**, FPS: **30**
   - «Выключать источник, когда он не виден» (Shutdown source when not visible) — **выкл**
   - «Обновлять браузер, когда сцена становится активной» — **вкл**
3. Фон оверлея прозрачный — графика ляжет поверх видео.

## Как пользоваться

- **Подготовка:** низ экрана закреплён — готовность ролей и «Начать игру» всегда видны.
  Когда дон, шериф и обе мафии назначены, появляется «Остальным — мирный» (шесть нажатий
  одним). «Начать игру» активна, только когда состав ролей полный.
- **Подготовка (данные):** введите название, ники (подсказки из справочника прошлых игр), загрузите
  фото (клик или drag-and-drop), назначьте роли (6 мирных, 2 мафии, дон, шериф) и нажмите
  «Начать игру». Кнопка «⇄» меняет игроков местами.
- **Длинный ник:** чтобы разбить ник на плашке оверлея на две строки, поставьте `|`
  в точке переноса: `Тёмный|Рыцарь`. Разделитель виден только в поле ввода — в протоколе,
  архиве и справочнике ник показывается с пробелом. Справочник запоминает ник вместе
  с `|`, так что перенос достаточно задать один раз.
- **День:** «Речь» — слово игроку (подсветка на оверлее, строка в панели подсвечивается и
  прокручивается в зону видимости, таймер речи стартует сам); кнопки 60/30 в шапке —
  перезапуск таймера. «Выставить» появляется на этапе выставления — кандидатура на голосование.
- **Порядок речей:** в обсуждении дня (этап выставления) панель ведёт круг: у сказавшего —
  «✓ говорил», повторно слово ему не выдать; следующий по кругу (мимо выбывших)
  подсвечен пунктиром с меткой «следующий» — это подсказка, слово можно дать кому угодно.
  День открывает следующий после открывавшего прошлый день. В панели голосования —
  счётчик «Ходы: N из M». Речи на голосовании и прощальные в круг не входят.
- **Молчанка:** 3-й фол — игрок теряет ближайшую речь: в текущем дне, если ещё не
  говорил, иначе в следующем. Ход у него остаётся: вместо «Речь» кнопка «Ход» — без
  речи и таймера, но выставить кандидатуру он может. Снятый фол снимает и молчанку.
- **Угадайка** (за столом 3–4 игрока): молчанка не лишает речи — у игрока с 3 фолами
  кнопка «Речь 30с», таймер ставится на короткую речь (настройка «Короткая речь»).
  Блокировки только в панели — сервер слово никому не запрещает.
- **Раскладка панели:** на широком экране (от 1000px — ноутбук, iPad в альбоме) днём —
  две колонки: игроки слева, панель голосования справа, всегда на виду. На планшете
  в портрете и на телефоне панель голосования прилипает к низу экрана. Ночью три ночных
  блока стоят в ряд (на экране уже 1000px — столбиком). На старом iPad (1024×768) все
  десять игроков помещаются без прокрутки в обеих ориентациях: на невысоком экране
  строки игроков компактнее, а на iPad в портрете строка остаётся однострочной.
- **Голосование:** «Начать голосование», затем кандидаты идут списком, под ним — одна
  общая клавиатура голосов 0…N: нажмите число для выделенного кандидата, выделение само
  перейдёт к следующему (нажатие на кандидата — вернуться и исправить),
  «Завершить голосование» — итог рассчитывается автоматически (равенство → перестрелка →
  «поднять всех»).
- **Ночь:** кнопка «Ночь N →» в шапке; блоки «Отстрел», «Проверка дона», «Проверка шерифа».
  Как только в блок введён выбор, он закрывается заглушкой «✓ Выбор сделан» — номера
  не видны сидящим рядом. Ошиблись — «Отменить» в шапке.
- **ЛХ:** при первой смерти в первую ночь панель сама предложит ввести лучший ход.
- **Фолы:** «+/−» на карточке; на 3-м фоле пометка «без речи», на 4-м — предложение удалить.
- **Отмена:** «Отменить» (↶) откатывает последние действия (до 50 шагов).
- **Горячие клавиши** (ноутбук): пробел — старт/пауза таймера, Ctrl+Z — отмена.
  Не срабатывают, пока курсор в поле ввода или открыто окно.
- **Индикатор оверлея:** если игра идёт, а источник OBS не подключён, в шапке горит
  оранжевое «нет оверлея» — эфир сейчас без графики.
- **Завершение:** меню ☰ → «Завершить игру» → результат. Протокол доступен из архива
  (☰ → «Архив игр») — печатная страница и JSON-экспорт.
- **Тумблеры оверлея:** меню ☰ — показать/скрыть плашки, трекер, бар голосования, роли.
  «Роли на плашках» выключает и цвет номеров по ролям в трекере и баре голосования —
  иначе цвет выдавал бы роли зрителям.
  (Таймер речи на оверлей пока не выводится — он только в шапке панели.)
- **Что видит зритель:** слева вверху, над трекером — чип фазы «День N / Ночь N»
  (после игры — итог); справа вверху — название турнира. Новый фол отмечается вспышкой точки на плашке — только
  на живое событие: перезагрузка источника в OBS её не повторяет.

## Защита панели токеном

По умолчанию **выключена**: панель и API открыты всем в локальной сети. Это осознанно —
панель открывают перед эфиром, и обязательный вход, отказавший в неподходящий момент,
хуже, чем открытый доступ в доверенной сети клуба.

Включается одной строкой в `config.json`:

```json
"auth": {
  "token": "придумайте-длинную-строку"
}
```

После перезапуска сервера панель открывается по адресу с токеном:
`http://localhost:3000/control?token=придумайте-длинную-строку`. Токен сохранится в
httpOnly-куки на 30 дней и уберётся из адресной строки — дальше открывайте обычный адрес.
То же самое на планшете: один раз зайти по ссылке с токеном.

**Что закрывается:** панель `/control` и весь `/api`, включая отправку игры в рейтинг.
**Что остаётся открытым:** `/overlay` и `/uploads` — Browser Source в OBS не умеет логиниться,
менять URL источника не нужно.

Открытый оверлей не даёт управлять игрой: WebSocket-соединения с `role=overlay` работают
только на чтение, и действия от них сервер игнорирует — независимо от того, задан токен или нет.

## Интеграция с трекером рейтинга

Оверлей умеет обмениваться данными с трекером **Iron Maf / MafiaClubTracker** в обе стороны:
подтягивать игроков (ник + аватар) в свой справочник и отправлять туда результаты
сыгранных игр. По умолчанию интеграция выключена.

### Настройка

1. Если файла `config.json` нет — скопируйте `config.example.json` в `config.json`
   (в корне проекта, рядом с `package.json`).
2. Откройте свой проект трекера в Supabase → **Project Settings → API** и скопируйте
   `service_role`-ключ (не `anon`!) и URL проекта.
3. Впишите их в блок `tracker` в `config.json`:

   ```json
   "tracker": {
     "enabled": true,
     "supabaseUrl": "https://ВАШ-ПРОЕКТ.supabase.co",
     "serviceRoleKey": "service_role-ключ из Supabase трекера"
   }
   ```
4. Перезапустите сервер оверлея (`npm start`).

`service_role`-ключ остаётся **только на сервере оверлея** и в браузер не передаётся, поэтому
`config.json` добавлен в `.gitignore` — не публикуйте и не коммитьте его. Если блок `tracker`
не настроен или `enabled: false` — кнопки ниже не показываются, остальная работа оверлея
не меняется.

### Импорт игроков (трекер → оверлей)

На экране «Подготовка игры» появится кнопка **«⬇ Импорт из рейтинга»**: клик загружает
игроков из трекера в справочник оверлея, и их ники сразу доступны при вводе состава
(аватар подставляется автоматически, локальные фото без аватара в трекере не затираются).

### Отправка игры (оверлей → трекер)

На экране завершения игры появится кнопка **«⬆ Отправить в рейтинг»**. Для отправки нужно,
чтобы:
- все 10 мест были выбраны из справочника (ник введён вручную, без выбора из подсказки —
  не подойдёт: место должно быть привязано к игроку трекера);
- в трекере был активный сезон (Season → `is_active`).

Отправка создаёт (или находит по названию+дате) турнир, определяет номер игры и записывает
саму игру и результаты всех игроков. Повторный клик по уже отправленной игре переспросит
подтверждение («В трекере появится дубль»). Ошибки (нет сезона, не все места привязаны,
трекер недоступен) показываются тостом с понятным текстом.

## Надёжность

- Состояние автосохраняется в `data/autosave.json` — перезапуск сервера или OBS ничего не теряет.
- Оверлей при обрыве связи тихо переподключается, не показывая ошибок в кадре.
- Завершённые игры складываются в `data/games/`, фото игроков — в `uploads/`.

## Тесты

```
npm test
```

Отдельно запускать сервер не нужно: каждый файл тестов сам поднимает его на свободном
порту и во временном каталоге, поэтому прогон **не трогает** боевые `data/` и `uploads/`
и его можно делать хоть посреди подготовки к трансляции.

Файлы находятся встроенным поиском `node --test` по маске `test-*.mjs`, поэтому
`tests/helpers/` и `tools/` в прогон не попадают. Один файл:
```
node --test tests/test-scenario.mjs
```

Что покрыто: сквозной сценарий игры, баллы и протокол, замечания заказчика (голосование,
попил, ночные проверки), отмена действий, восстановление после перезапуска, импорт из
трекера и обработка картинок.

Линтер: `npm run lint`. То же самое гоняется в CI на каждый push (`.github/workflows/ci.yml`).

### Дев-утилиты

Не тесты, в прогон не входят — нужны для визуальной проверки при работающем сервере:
```
node tools/demo-state.mjs   # набивает демо-состояние игры для просмотра оверлея
node tools/shot.mjs <url> <файл.png> <ширина> <высота>   # скриншот через Chrome
```

## Структура проекта

```
server/   — Node.js-сервер (Express + ws): состояние, действия, автосейв, REST
public/   — статика: /control (панель), /overlay (оверлей), /shared (общие модули:
            константы, SVG-иконки icons.js, шрифт Roboto Condensed в fonts/ — локально, OFL)
tests/    — тесты (node:test), поднимают сервер сами; tests/helpers — харнесс
tools/    — дев-утилиты: демо-состояние, скриншоты
data/     — autosave.json, справочник игроков, архив игр (создаётся при работе)
uploads/  — фотографии игроков (создаётся при работе)
config.json — порт, значения по умолчанию и настройки трекера (не коммитится; шаблон config.example.json)
start.bat — двойной клик для запуска на Windows
```
